# com.lexting.spatialgesturetext

Unity 6 package for Lexting dual-volume spatial text entry.

- **Reference scene:** `Scenes/main_01_twozone.unity`
- **Install:** add to the host project `Packages/manifest.json`:

```json
"com.lexting.spatialgesturetext": "file:../../Lexting_Unity_Plugin"
```

(or Git URL with `?path=/Lexting_Unity_Plugin` when published)

- **Third-party embeds:** see [ThirdPartyNotices.md](ThirdPartyNotices.md). Do **not** add a second UniRx/SimpleJSON/Surge copy in the host project.
- **Quest demo APK:** [Releases/tutorial_demo.apk](Releases/tutorial_demo.apk) (when published)

Public onboarding: repository root [README.md](../README.md) (Getting Started).
